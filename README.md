# Amazon-Sales-Project

📊 Amazon Sales SQL Case Study
Welcome to the Amazon Sales SQL Project! This portfolio case study explores how SQL can be used to analyze key business operations in an Amazon-like e-commerce environment. The project focuses on customer orders, product performance, shipping efficiency, and regional sales behavior — providing insights that drive smarter business decisions.

📂 Project Overview
This project analyzes a relational dataset consisting of orders, order items, products, and shipping data. The goal is to simulate real-world analytical thinking and answer questions a business manager would ask.

Key Objectives:

Analyze revenue trends over time and by category

Identify top-performing cities, states, and product segments

Detect delays in shipping and fulfillment performance

Understand customer ordering patterns and product demand

⭐ Key Highlights
Data Sources: orders.csv, order_items.csv, products.csv, shipping.csv

Primary Goal: Use SQL to extract actionable insights and solve real business problems

Tech Stack: MySQL, SQL Workbench, PowerPoint

Skills Applied:

Joins, Aggregation, Filtering

Window Functions (RANK, ROW_NUMBER, LAG)

CTEs and Subqueries

Date-based and rolling trend analysis

📝 Project Files
📁 Datasets:
orders.csv: Contains order dates and customer IDs

order_items.csv: Product IDs, quantities, and item prices per order

products.csv: Product names and categories

shipping.csv: Shipping service, city, state, postal code, and courier status

🔍 Insights & Findings
Top Revenue Contributors: Certain cities and categories drive a major share of sales

Shipping Delays: Fulfillment by certain methods shows higher delay rates

Category Performance: High-performing categories help shape inventory decisions

Rolling Revenue Trends: 7-day and monthly trends reveal seasonal spikes and slowdowns

📌 Summary
This hands-on SQL project highlights how structured data analysis can guide decisions in e-commerce. From identifying where your revenue is coming from to detecting fulfillment inefficiencies, this portfolio demonstrates the value of analytical thinking backed by SQL.
